## 🎓 RESEARCH CLUB MEMBERS & INTERVIEW SELECTION PIPELINE

Other students become Research Club Members strictly through an interview selection process:
```
Student Application
       │
       ▼
Interview Process (Pending Interview Status)
       │
       ▼
Selection Approval (Faculty Coordinator / President / Vice President)
       │
       ▼
Research Club Member Profile Created (Member ID: RISE-2026-XXX)
       │
       ▼
Individual Member Login Account Generated (Unique PRN + Private Hashed Password)
```

---

## 🔒 STRICT PRIVACY DIRECTIVES

1. **Member Password Privacy**:
   - Passwords are encrypted (`passwordHash`) and **NEVER displayed anywhere** (not in profiles, admin lists, public pages, team cards, dashboards, search results, or logs).
   - Faculty, President, and VP cannot view existing passwords — they only have a **Reset Password** function to assign a new temporary password.

2. **Member Email Privacy**:
   - Member emails are kept private and hidden on public pages and team cards. Only authorized administrators can access contact info in private admin portals.

## 🚀 GETTING STARTED

### Prerequisites
- Node.js `v18+`
- npm `v9+`

### Installation & Local Run
```bash
# Install dependencies
npm install

# Run Vite local dev server
npm run dev

# Build for production
npm run build
```
